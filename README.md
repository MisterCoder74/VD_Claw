# VD_Claw 🦾

Next-Generation AI-Powered Web Intelligence & Extraction Engine.

## Features
- **Standard Claw**: Simple and efficient web scraping and data extraction.
- **CRO Comparison**: Compare up to 4 URLs to analyze conversion potential and UX patterns.
- **Enhanced Extractor**: Deep analysis with visual tables and comprehensive HTML reports.
- **Local Analysis**: Process local `.html`, `.csv`, `.txt`, and `.json` files using neural logic.
- **High-End UI**: Modern dark-mode interface with glassmorphism and neon aesthetics.
- **Multi-Format Export**: Download results in JSON, Markdown, or HTML formats.

## Tech Stack
- **Frontend**: Vanilla JS, Inter & Lexend Fonts, FontAwesome, Marked.js.
- **Backend**: PHP (CURL, DOMDocument).
- **AI**: OpenAI GPT-4o-mini via API.

## Setup
1. Configure `config.json` with your desired OpenAI settings.
2. Serve the project via a PHP-enabled web server.
3. Enter your OpenAI API Key in the UI to start clawing.
